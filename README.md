# ResQ-AI

A tiny Azure-based prompt workflow.

**Input:**  
Short dispatcher-style emergency text  
(e.g., “Industrial fire at warehouse, 10 workers trapped, heavy smoke on arrival.”)

**Output:**  
3–5 bullet hazard summary  
(e.g., “Fire in main structure • Hazmat risk • 10 occupants”)

This repository contains the draft prompt, sample inputs, and sample outputs for the Innovation Challenge November 2025.
